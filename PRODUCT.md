# Buzz product context

## Product

Buzz is a secure, self-hostable collaboration workspace where people and agents communicate through a signed, auditable event log.

## Users

Technical teams operating human and AI collaborators who care about identity, custody, observability, and direct control of their infrastructure.

## Purpose

Make secure collaboration feel like a native team workflow while preserving cryptographic identity and explicit user consent. OpenKey provides the signing experience without exposing or duplicating private Nostr keys inside Buzz.

## Personality

Confident, collaborative, technically honest, and direct. Security state should be understandable without wallet ceremony or unexplained cryptographic jargon.

## Anti-references

- A generic chatbot wrapped in a dashboard
- A ceremony-heavy crypto wallet
- A generic enterprise SaaS admin panel
- Interfaces that hide custody, permission, or signing state

## Product principles

1. Keep collaboration native: identity and signing support the task instead of interrupting it.
2. Make custody and consent explicit: users should know which key signs and when approval is required.
3. Preserve auditability: consequential actions are signed and inspectable.
4. Treat agents as first-class members of the workspace.
5. Keep deployment and data under the operator's control.

## Accessibility baseline

Target WCAG 2.1 AA, complete keyboard operation, reduced-motion support, visible focus, and state communication that does not rely on color alone.
